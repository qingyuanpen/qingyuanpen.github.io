本轮处理中观察到未充分分散的样品。后续处理阶段，一份平行样本发生外源液体进入，导致体系组成和可比性失去控制；其余样本正在继续第二次提取阶段。

    继续候选流程

    未受污染的平行样本正在继续第二次提取，并作为过程样本跟踪；具体操作仅保留在内部记录。

  4. C · STOP
    外源液体进入

    受影响样本的体系组成与污染风险失去控制，随即登记为异常样本并停止后续操作。

该偏差不是简单的体积变化，而是体系组成、污染风险与处理条件同时失去控制，因此受影响样本不再具备与其他平行样本的可比性。

D 组｜褐变、黑色杂质与整组停止

D 组代表候选流程二。处理过程中先观察到褐变，进入第二次提取阶段后又发现黑色杂质。由于样品完整性与污染来源无法确认，整组在该阶段停止。

偏差如何影响数据解释？

DEV-A · SAMPLE LOSS

A 组部分样本溶液泄漏

影响：未知量脂质与溶剂损失，可能改变最终浓度。处置：保留偏差记录，正式定量前需完成有效性判断或重做。

QC-B · WITHIN-BATCH VARIATION

B 组质量提示，不是操作异常

影响：同批技术平行之间存在较明显差异。处置：保留全部数据，不事后删除；下一轮复核混匀、取样和恒重判据。

DEV-C · CONTAMINATION

C 组一份样本发生外源液体进入

影响：体系组成、缓冲状态和污染风险失控。处置：停止后续操作，从有效 C 组平行样本中排除。

DEV-D · APPEARANCE

D 组处理过程中褐变

影响：提示样品可能发生氧化、降解或其他变化，但仅凭颜色不能确定机制。处置：记录并避免把原因写成既定结论。

DEV-D · PARTICULATE

D 组发现黑色杂质

影响：样品来源、容器、环境或试剂污染均未排除。处置：整组停止，不进入有效的 C/D 工艺比较。

当前能得出什么结论？

CURRENT DECISION

本批次尚不能支持两条候选流程的有效比较。

B 组基线测定虽然已完成，但 C 组一份样本因外源液体进入而失去可比性，D 组又因褐变和黑色杂质整组停止。当前记录能证明的是“本轮比较受到关键过程偏差干扰”，而不是证明某条候选流程本身导致失败。

A 组已经到脂质定溶阶段，但部分样本的泄漏意味着后续定量有效性仍需单独评估。B 组的组内差异也应作为质量提示保留。将这些事实公开写入记录，可以防止未来在整理图表时把受影响数据误当成正常重复。

待补记录与下一步

  • 完成 A 组显色定量。 先确认受泄漏影响样本的有效性，再完成标准曲线、读数和单位换算。
  • 复核 B 组组内差异。 下一轮预先锁定恒重判据，并强化分样前混匀和称量过程记录。
  • 继续记录 C 组终点。 补齐未受污染样本第二次提取的结束状态和样本去向。
  • 补齐样本流转。 记录各样本当前容器、保存位置、封口方式与最终处置。
  • 补齐影像证据。 若已有照片，关联大块未分散物、D 组褐变、黑色杂质和泄漏痕迹。
  • 重新建立 C/D 配对。 后续比较应使用同批平行样本，并在预先锁定且保持一致的条件下重新开始。
