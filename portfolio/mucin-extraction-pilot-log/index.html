偏差如何影响数据解释？

DEV-A · SAMPLE LOSS

A 组部分样本溶液泄漏

影响：未知量脂质与溶剂损失，可能改变最终浓度。处置：保留偏差记录，正式定量前需完成有效性判断或重做。

QC-B · WITHIN-BATCH VARIATION

B 组质量提示，不是操作异常

影响：同批技术平行之间存在较明显差异。处置：保留全部数据，不事后删除；下一轮复核混匀、取样和恒重判据。

DEV-C · CONTAMINATION

C 组一份样本发生外源液体进入

影响：体系组成、缓冲状态和污染风险失控。处置：停止后续操作，从有效 C 组平行样本中排除。

DEV-C · PARTICULATE

C 组出现未鉴定深色颗粒

影响：样品、容器、环境或试剂相关来源均未排除。处置：保留照片和归属纠正记录；鉴定前不写成污染或工艺因果。

DEV-D · APPEARANCE

D 组褐变且上清黄褐、浑浊

影响：可能提示样品发生变化，但仅凭颜色和浑浊度不能确定机制。处置：记录外观并保持整组停止，不把原因写成既定结论。

当前能得出什么结论？

CURRENT DECISION

本批次尚不能支持两条候选流程的有效比较。

B 组基线测定虽然已完成，但 C 组一份样本因外源液体进入而失去可比性，C 组又出现未鉴定深色颗粒；D 组则发生褐变和黄褐色浑浊，并在第二次加入提取介质后停止。当前记录能证明的是“本轮比较受到关键过程偏差与未决外观观察干扰”，而不是证明某条候选流程本身导致失败。

A 组已经到脂质定溶阶段，但部分样本的泄漏意味着后续定量有效性仍需单独评估。B 组的组内差异也应作为质量提示保留。将这些事实公开写入记录，可以防止未来在整理图表时把受影响数据误当成正常重复。

待补记录与下一步

  • 完成 A 组显色定量。 先确认受泄漏影响样本的有效性，再完成标准曲线、读数和单位换算。
  • 复核 B 组组内差异。 下一轮预先锁定恒重判据，并强化分样前混匀和称量过程记录。
  • 继续记录 C 组终点。 补齐 7 月 27 日恢复处理后的结束时刻、累计时长、终点外观和样本去向。
  • 核对深色颗粒归属。 从原始管身标记和实验本确认具体对应平行份；在鉴定前只保留外观描述。
  • 核对 D 组停止依据。 区分已确认的褐变/浑浊观察与尚未回填的现场停止判断。
  • 补齐样本流转。 记录各样本当前容器、保存位置、封口方式与最终处置。
  • 继续维护影像证据。 新照片应在当天关联实验阶段、组别、文件名与解释边界。
  • 重新建立 C/D 配对。 后续比较应使用同批平行样本，并在预先锁定且保持一致的条件下重新开始。
