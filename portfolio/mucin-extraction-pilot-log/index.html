RECORD AT A GLANCE

  • 样品来源为羊大肠黏液；本页仅记录本轮 A/C/D 组进度，B 组不在本次更新范围内。
  • 这是脱敏公开版；离心、补液、搅拌和保存的精确参数仅保留在内部实验记录中。
  • C2 的冰水渗入改变了体系体积与组成，不能再作为 C 组有效平行样本。
  • D 组先出现褐变，后发现黑色杂质；原因尚未证实，停止操作不等于证明“无丙酮工艺失败”。

C 组｜PBS 提取进度与 C2 冰水渗入

C 组为保留丙酮脱脂步骤的比较流程。本轮记录显示，首次 PBS 搅拌后仍有大块未分散物；随后完成低温静置、离心、补加 PBS 与第二次冰浴搅拌。C2 在第二次搅拌阶段发生严重体积污染。

  1. C · 01
    首次 PBS 搅拌

    搅拌后可见大块未分散物，表明样品尚未形成均一分散体系。

  2. C · 02
    低温静置

    未分散体系随后转入低温环境静置；精确温度与时长不在公开版披露。

  3. 2026.07.24
    离心并补加 PBS

    离心后收集上清，并为各份样品补加 PBS；离心与补液参数保留在内部记录中。

  4. 2026.07.24
    第二轮冰浴搅拌

    本阶段继续促进样品在 PBS 中分散与提取。完成本轮搅拌后，C1/C3 转入低温环境过夜。

  5. 2026.07.24 · C2 STOP
    冰水大量渗入

    冰浴融化后发生倾倒，冰水进入 C2。C2 随即作为异常样本转入低温保存，不参与后续操作。

C2 的问题不是“多了一点水”，而是体系体积、PBS 浓度、潜在污染与提取条件同时失去控制，因此不再具备与 C1/C3 的可比性。

D 组｜褐变、黑色杂质与整组停止

D 组用于观察删除丙酮步骤后的 PBS 提取过程。该组在首次长时间室温搅拌后出现褐变，低温保存后继续处理时又发现黑色杂质。由于样品完整性与污染来源无法确认，未继续后续实验。

  1. D · 01

偏差如何影响数据解释？

DEV-A · SAMPLE LOSS

A1/A2 定溶液泄漏

影响：未知量脂质与溶剂损失，可能改变最终浓度。处置：保留偏差记录，正式定量前需完成有效性判断或重做。

DEV-C2 · CONTAMINATION

C2 冰水大量渗入

影响：体积、离子强度、缓冲能力和污染风险失控。处置：停止后续操作，从有效 C 组平行样本中排除。

DEV-D1 · APPEARANCE

D 组搅拌后褐变

影响：提示样品可能发生氧化、降解或其他变化，但仅凭颜色不能确定机制。处置：记录并避免把原因写成既定结论。

DEV-D2 · PARTICULATE

D 组发现黑色杂质

影响：样品来源、容器、环境或试剂污染均未排除。处置：整组停止，不进入有效的 C/D 工艺比较。

当前能得出什么结论？

CURRENT DECISION

本批次尚不能回答“删除丙酮是否可行”。

C2 因冰水渗入失去可比性，D 组又因褐变和黑色杂质整组停止。当前记录能证明的是“本轮比较受到关键过程偏差干扰”，而不是证明无丙酮流程本身导致失败。

同样，A1/A2 的泄漏意味着本轮脂质基线数据需要单独评估。将这些偏差公开写入记录，可以防止未来在整理图表时误把受影响数据当成正常重复，也为重新设计更稳定的搅拌、低温控制和样本转移流程提供依据。
