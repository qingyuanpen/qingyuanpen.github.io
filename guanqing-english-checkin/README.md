# 冠清英语打卡

一个专注于日常英语学习记录的静态网站，支持：

- 词汇新词与复习数量记录
- Listening 材料与 Section 记录
- IELTS Reading / Writing / Speaking 主任务
- 论文摘要或深读记录
- 口语录音上传与浏览器内录音
- 本地自动保存、连续打卡、月历与近七天统计
- 生成、下载或分享 1080 × 1440 PNG 打卡图片
- 数据保险箱：完整 JSON 备份、导入恢复和每周备份提醒
- IndexedDB 最近版本快照，最多保留 20 个版本

## 数据说明

网站不需要登录，学习记录默认保存在当前设备的浏览器本地存储中。建议每周从“数据保险箱”下载一次完整备份，并保存在安全的本地文件夹。

版本快照用于撤销误操作，但它仍属于浏览器数据；如果浏览器网站数据被清除，快照也可能一并丢失，因此不能替代下载备份。

录音文件不会上传到服务器，也不会包含在 JSON 备份中；现场录音请在完成后单独保存。

## 本地预览

这是一个无构建依赖的静态网站，可直接打开 `index.html`，或使用任意静态文件服务器预览。

## GitHub Pages

推送到 `main` 分支后，仓库中的 Pages 工作流会自动部署网站。
